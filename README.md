# TANVI Birthday QR Website 💕
A free, static, mobile-friendly birthday surprise page.

## Files
- index.html
- style.css
- script.js

## Free hosting with GitHub Pages
1. Create/login to a GitHub account.
2. Create a NEW PUBLIC repository, e.g. `tanvi-birthday`.
3. Upload all 3 files into the repository root.
4. Open Settings → Pages.
5. Under "Build and deployment", choose "Deploy from a branch".
6. Select `main` and `/ (root)`, then Save.
7. Wait a few minutes. GitHub will show your live website URL.
8. Open the URL on your phone to test it.
9. Generate a QR code from that live URL using any free QR generator.

## Important
The website itself is free. The QR code can also be generated free.
Do not upload private/personal information to a public repository.
